# HouseLens v1.5 — free adjustable property search

This is an incremental patch for v1.4. **Keep your current `web/data/state.json` unchanged.**

See `APPLY-V1.5.txt` for deployment and secret setup instructions.

**Source:** [Untera Developer API](https://untera.io/developers) — free 1,000 requests/day, visible attribution required; Billericay coverage not yet verified with an issued key.

The site filters GBP asking prices, bedrooms, property type and distances from Billericay station. Unverifiable coordinates appear separately. On-demand searches use a personal API key from your browser; Tuesday/Friday saved snapshots use a GitHub Actions secret. Real provider coverage may be incomplete and coordinates approximate.
